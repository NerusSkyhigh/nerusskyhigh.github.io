    Controllo del flusso

    Con "controllo del flusso" si intence una serie di comandi che permettono di controllare l'esecuzione di diversi comandi sulla base di condizioni logiche. I due casi fondamentali sono i seguenti:

    • se la condizione A è vera, allora esegui il comando C1; altrimenti il comando C2
    • finché la condizione A è vera, esegui il comando C; poi procedi con il resto del programma

    Controllo del flusso nel linguaggio C

    In C, il flusso di un programma viene controllato con i seguenti costrutti.

    1. Albero decisionale if-else if-...-else,
    2. Ciclo while,
    3. Ciclo do ... while,
    4. Ciclo for,
    5. Comando goto -> label.

    Gli alberi decisionali si usano quando bisogna scegliere quali porzioni di codice eseguire sulla base di condizioni logiche. I cicli si utilizzano per ripetere una porzione di codice, eventualmente con poche variazioni. Si usano ad esempio per ripetere una stessa operazione su una serie di input diversi. Il comando goto infine permette di saltare da una riga di codice ad un'altra.

    Cicli while e do-while

    Nel ciclo while viene verificata una condizione logica -- i<10 nell'esempio qui soto -- ed il blocco di codice seguente viene eseguito finché la condizione resta vera. Che valore viene stampato dal codice seguente?

    ciclo while
    int i = 0;
int s = 0;
while(i<10) { 
    s += i;
    i += 1; //(1)
}
printf("s=%d\n",s);
    1. Attenzione: se vi dimenticate di incrementare i la condizione resterà sempre vera...

    Una condizione può essere anche composta da più elementi:

    ciclo while doppia condizione
    int i = 0;
int s = 0;
while(i<10 && s<125) { //(1) 
    s += i*i;
    i += 1;
}
printf("s=%d\n",s);

    1. OK, questo è un esempio molto stupido, ma la doppia condizione può essere molto utile in generale.

    Il ciclo while valuta la condizione prima di eseguire il codice anche una sola volta. Se avessimo inizializzato int i=10;, il codice non sarebbe mai stato eseguito. Il ciclo do-while invece pone la condizione per continuare l'esecuzione del codice dopo averlo eseguito una volta. Questo può essere importante quando si vuole uscire da

    ciclo do-while
    int i=10;
int s=0;
do {
    s += i*i;
    i += 1;
}while(i<10);
printf("s=%d\n",s); // (1)

    1. Cosa stampa questo codice?

    Il ciclo do-while è molto utile per leggere gli input dall'utente. Usando come condizione la correttezza dell'input letto questo permette di riproporre il prompt all'utente finché i dati forniti da questo non rispettino le condizioni volute.

    input con do-while
    int n;
double d;
int i = 0;
do {
    printf("Inserire un intero positivo\n");
    i = scanf("%d", &n);
    printf("Inserire un numero in virgola mobile negativo\n");
    i += scanf("%lf", &d); // (1)
}while(i != 2 && n <=0 && d>=0 );
    1. scanf ritorna il numero di argomenti letti correttamente, quindi va aggiornato in questo esempio.

    Il ciclo for

    I cicli while e do-while si usano in genere quando non conosciamo in anticipo il numero di volte in cui vanno ripetute le operazioni. Ad esempio perché la condizione ha un carattere randomico, o è legata a input dell'utente, come visto sopra. Il ciclo for invece è ottimale per eseguire un numero prestabilito di passi. Per due motivi 1. È più chiaro per chi poi legge e mantiene il codice, 2. È chiaro al compilatore, che può quindi produrre codice più veloce.

    Un ciclo for semplice funziona come segue

    ciclo for semplice
    int sum=0;
int N=100;
for(int i=1; i<=N;i+=1) { //(1) lo statement definisce la variabile del ciclo
    sum += i;
}
printf("sum = %d ; gauss = %d\n,  sum, N*(N-1)/2);

    La prima riga del ciclo for stabilisce tutto quello che serve per eseguire il ciclo: 1. La condizione iniziale: int i=1; 2. La condizione che deve rimanere vera durante l'esecuzione del ciclo: i<=N; 3. La regola con cui viene modificato i: i+=1. La condizione 2. viene valutata all'inizio, quindi questo ciclo è equivalente al seguente ciclo while. 

    int sum=0;
int N=100;
int i=1;
while(i<=N) { 
    sum += i;
    i += 1;
}
printf("sum = %d ; gauss = %d\n,  sum, N*(N-1)/2);

    Bisogna fare attenzione ad alcune cose nel lavorare con i cicli for.

    1. La variabile del ciclo, i nell'esempio di sopra, può anche essere stata dichiarata fuori da questo. Ciò non è vietato, ma lo sconsigliamo in quanto potrebbe portare a riutilizzare una variabile utilizzata in altre parti del codice cambiandone il valore in modo difficile da individuare.
    2. L'incremento / decremento della variabile interna può essere quello che vogliamo, purché generi degli interi con segno.
    3. La variabile del ciclo può essere ulteriormente modificata all'interno dello stesso.

    Un esempio contorto:

    #include <stdio.h>

int main() {
    int j;
    int k = -1;
    for(j = 2; j < 7; j+=k) {
        k++;
        j+=2;
    }
    printf("La variabile k vale %d\n", k);
    return 0; 
}

    Le condizioni possono anche essere vuote, dando un ciclo infinito equivalente a while(1) {...}.

    for(;;) { 
// loop infinito
}

    Infine, i cicli for possono raccogliere più condizioni iniziali e di update, cioè, possono lavorare su più variabili!

    Un ciclo for più complesso. Cosa stampa?
    int j = 2;
for(int i=0, j=10; i<j; i++, j--) { //(1)
    printf("%d %d\n", i,j);
}//(2)
    1. Cosa stampa secondo voi questo ciclo?
    2. i=0, j=10, ... i=5, j=5.

    Il comando goto

    Nei primi linguaggi di programmazione il comando goto si usava per implementare tutto il controllo del flusso. Nel software moderno il suo utilizzo è estremamente malvisto, in quanto l'abuso di goto non permette di capire agilmente la logica del programma.
